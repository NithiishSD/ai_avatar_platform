# 06 — UI

React 19 + Vite 6, plain JSX (no TypeScript), no UI framework. Talks to the
API at `http://localhost:8000` by default.

## Screens

| Area | Component | Does |
|---|---|---|
| Speech | `App.jsx` | text, mode, language, emotion, speed/pitch, clone voice picker, synthesise, audio player, live viseme indicator, phoneme timeline |
| Avatar | `AvatarPanel.jsx` | avatar picker, landmark + bbox canvas overlay, register photo with consent basis, render button, progress, video player, SyncNet score |
| Live (M4) | new | start/stop session, text or mic input, streamed avatar frames |
| Provenance (M5) | new | upload a file, show whether it carries our marks |

## Every async view has four states

| State | Shown as |
|---|---|
| empty | instruction text, primary action enabled |
| loading | progress (job `progress` when known), action disabled |
| error | the API's `detail` text verbatim, retry possible |
| success | the result (audio, video, score) |

## E2E coverage

Playwright drives the real backend and the real dev server
(`frontend/e2e/`). Selectors use roles and labels, not CSS classes.

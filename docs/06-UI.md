# 06 — UI

React 19 + Vite 6, plain JSX (no TypeScript), no UI framework. Talks to the
API at `http://localhost:8000` by default.

## Screens (redesigned 8 Oct, owner's request I-03)

Three tabs. Development-only controls were removed from the screen; the API, SDK and `/docs` still offer them.

| Tab | Component | Does |
|---|---|---|
| Create video | `CreateVideo.jsx` + `FacePicker.jsx` | 1 Face: portrait cards; "Add a photo" / "Generate a face" / "Restyle this face" behind small buttons. 2 Script & voice: standard voice, clone a voice (reference + engine), or "Use my recording" (file, whose voice, optional transcript); language search; emotion chips; speed, pitch and two-speaker dialogue under "More voice options". 3 Video: size (preview / 1080p), lip sync (standard / Wav2Lip), background colour. One **Create video** button runs speech then video (or voice-to-avatar) and shows the voice used, the video, the watermark line, manifest and download links, and an optional lip-sync measurement |
| Live avatar | `LivePanel.jsx` | start/stop a session, speak text, interrupt (stops queued audio too), microphone input |
| Verify a file | `ProvenancePanel.jsx` | upload a file (and its manifest), see the evidence and the verdict |

**Removed from the screen** (still in the API): task id / status / model boxes, the live viseme indicator and phoneme timeline, the "Router will select" and MMS model badges,
the alignment checkbox (always on), the speech-quality audit, the quality menu (its "high" tier routes to Higgs, which cannot run here), the style menu (only dialogue
worked; now a checkbox), the landmark overlay, the "Phase 3" subtitle.

## Every async view has four states

| State | Shown as |
|---|---|
| empty | instruction text, primary action enabled |
| loading | progress (job `progress` when known), action disabled |
| error | the API's `detail` text verbatim, retry possible |
| success | the result (audio, video, score) |

## E2E coverage

Playwright drives the real backend and the real dev server
(`frontend/e2e/`). Selectors use roles and labels, not CSS classes.
